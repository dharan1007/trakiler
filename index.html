FORM Club

Compete on consistency, not noise.

Daily ranks combine completed work, active minutes, steps, volume normalized by body weight, and streak consistency. The score is transparent and capped so one extreme number cannot dominate. Global mode uses Supabase when configured; until then the same interface works in private local mode.
