# Changelog

All notable public FORM releases are documented here.

FORM follows semantic-versioning-style release labels for the public product/distribution surface. A version number describes the software release, not scientific validation or medical maturity.

## [0.9.0] — 2026-08-08

### Added

- First formal GitHub release channel.
- Detailed product/research README with feature matrices, diagrams, program catalog, validation status and public/private source boundary.
- Security reporting and source-boundary policy.
- Citation metadata through `CITATION.cff`.
- Current-source/project rights notice with explicit historical-license caveat.
- Automated release packaging for the browser-delivered public surface.
- Reproducible container build for GitHub Container Registry.
- GitHub issue forms for bug reports, research/validation feedback and feature requests.
- Support/contact guidance.

### Product surface represented by this release

- Today workout execution and logging.
- Editable Programs.
- Progress analytics.
- Exercise intelligence.
- Decision-support layer.
- FORM Club.
- Profile, privacy, export, sync and deletion controls.

### Validation note

No FORM-wide accuracy percentage is claimed. Estimates and heuristics remain context-dependent and are documented as such.

### Security note

Browser-delivered implementation is inspectable by design. Confidential algorithms, backend implementation, schemas, architecture and private research should execute/live outside the public distribution repository.
