# FORM v0.9.0 — Public Research Preview

FORM v0.9.0 establishes the first formal GitHub release channel for the project.

## What FORM is

FORM is an independent research/side-project training system for private-first resistance-training logging, editable programming, progression analytics, exercise intelligence and transparent decision support.

Live app: https://dharan1007.github.io/trakiler/

## Included in this release

- Workout execution with set completion, load, repetitions, RIR, rest timing and notes.
- Editable 2–6 day training-program families and profile-aware program matching.
- Progress analytics for adherence, weekly streaks, estimated-strength trends, PRs, volume and weighted-set workload.
- Optional bodyweight and circumference logging.
- Searchable exercise intelligence with target muscles, execution cues, contextual FORM scores, alternatives and heat-map views.
- Decision-support concepts including readiness context, Session Rescue, exercise substitutions, plateau signals, goal alignment and conservative return-from-break context.
- Optional FORM Club publishing with a deliberately reduced public aggregate projection.
- Local-first operation, JSON export, optional cloud recovery/sync and deletion controls.
- Privacy Policy, Terms of Use, Security/source-boundary documentation and software citation metadata.

## Validation status

FORM does not claim a project-wide clinical or predictive accuracy percentage. Deterministic calculations, estimates, workload proxies, ranking heuristics and gamification scores are documented separately so users can distinguish measured inputs from inferred outputs.

Estimated strength, readiness, exercise scores, workload proxies, substitutions and program recommendations are contextual decision aids rather than medical diagnoses, certified coaching prescriptions or guarantees of outcomes.

## Privacy and safety

FORM is designed to work locally without requiring GPS, contacts, camera, microphone, wearable access or advertising identifiers. Public Club participation is opt-in and is intended to expose only reduced daily aggregates.

Do not place confidential credentials, service-role keys or private medical information in browser-delivered code or support reports.

## Distribution

This release provides GitHub-generated source archives plus a curated public-web artifact containing only files required to run the browser experience. A GitHub Container Registry workflow is also provided for reproducible local deployment of the public web surface.

## Project status

This is a research/side-project release, not a medical device or clinical system. The public repository is a showcase/distribution surface; proprietary backend, algorithmic, architecture and research internals are intended to migrate to a separate private source boundary.
